# Third-Party License Review

The detailed version and license inventory is maintained in [docs/THIRD_PARTY_LICENSES.md](../THIRD_PARTY_LICENSES.md).

The candidate pins runtime, MCP SDK, build, test, and Windows stdio dependency versions. License identifiers were read from installed distribution metadata and/or license texts present in installed artifacts during the CE-3 Windows environment check. No package source, wheel, or binary is vendored in this candidate.

This inventory identifies notices; it does not establish legal compatibility for every downstream distribution scenario. The lock files pin versions but not wheel hashes or a package index. If a wheel, executable, container, or bundled dependency artifact is produced, inspect the exact artifact contents, preserve required notices, and review each applicable license obligation. GitHub Actions are referenced by workflow but their source is not vendored.
